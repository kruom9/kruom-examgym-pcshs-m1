# Exam Gym แนวสอบเข้า ม.1 (จภ.) — โรงเรียนปิยมิตรวิทยา ฝ่ายมัธยม

เว็บฝึกโจทย์ฟรีสำหรับน้อง ป.6 เตรียมสอบเข้า ม.1 โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย รอบที่ 1
คณิตศาสตร์ 105 ข้อ · วิทยาศาสตร์ 108 ข้อ — ฝึกรายบทพร้อมเฉลย และข้อสอบจำลองจับเวลา 120 นาที

เปิดใช้งาน: https://kruom9.github.io/kruom-examgym-pcshs-m1/

- เว็บ static ล้วน ไม่ต้องล็อกอิน ไม่มี backend ไม่มี analytics ไม่เก็บข้อมูลส่วนบุคคล
  (ความคืบหน้าเก็บใน localStorage ของเครื่องผู้ใช้เท่านั้น)
